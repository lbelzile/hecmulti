# Classement de bières

Classement de bières

## Utilisation

``` r
biere
```

## Format

Une base de données avec 35 lignes et 7 variables:

- `classement`:

  entier, évaluation subjective de la qualité de la bière, soit très bon
  (1), bon (2) ou correct (3).

- `biere`:

  facteur, type de bière

- `cout`:

  double, coût pour 12 onces

- `calories`:

  double, nombre de calories

- `sodium`:

  double, sodium en milligrammes

- `alcool`:

  double, pourcentage d’alcool
