# Sélection du degré d'un polynôme

Un jeu de données simulées issues d'un modèle polynomial d'ordre inconnu
de la forme\$\$y = \sum\_{j=0}^{k} \beta\_{j}x^{j}.\$\$ Le vrai modèle
est cubique.

## Utilisation

``` r
polynome
```

## Format

Une base de données avec 100 lignes et 2 variables:

- `x`:

  variable explicative

- `y`:

  variable réponse
