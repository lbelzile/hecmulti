# Critère d'information BIC

Cette fonction retourne le critère d'information BIC

## Utilisation

``` r
# Méthode S3 pour summary.regsubsets
BIC(object, ...)
```

## Arguments

- object:

  un objet de classe `regsubsets`

- ...:

  arguments additionnels, actuellement ignorés

## Valeur de retour

vecteur avec critère d'information pour chaque modèle
