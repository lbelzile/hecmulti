# Prix de l'action Apple

Prix de l'action d'Apple

## Utilisation

``` r
aapl
```

## Format

Une base de données avec 313 lignes et 7 variables:

- `Date`:

  `Date`

- `Open`:

  double, prix à l'ouverture

- `High`:

  double, prix maximal quotidien

- `Low`:

  double, prix minimal quotidien

- `Close`:

  double, prix à la fermeture

- `Volume`:

  double, quantité d'actions transigées représentant volume de
  transaction

- `Adj_Close`:

  double, prix ajusté de fermeture
