# Promotion de produits

Données simulées pour un cas fictif de promotion de produits.

## Utilisation

``` r
logistclient
```

## Format

Une base de données avec 1000 lignes et 4 variables:

- `promo`:

  variable binaire, 1 si le client s’est prévalue d’une offre
  promotionnelle, 0 sinon

- `nachats`:

  nombre d’achats au magasin dans le dernier mois

- `sexe`:

  variable binaire, 0 pour les femmes, 1 pour les hommes

- `tclient`:

  variable catégorielle, soit `frequent` pour les clients réguliers ou
  `occasionnel` autrement
