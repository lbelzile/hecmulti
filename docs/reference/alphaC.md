# Alpha de Cronbach

Calcul de la mesure de cohérence interne pour la création d'échelles

## Utilisation

``` r
alphaC(x, na.rm = FALSE)
```

## Arguments

- x:

  matrice de variables numériques

- na.rm:

  logique; si `TRUE`, les valeurs manquantes sont enlevées avant le
  calcul

## Valeur de retour

alpha de Cronbach
