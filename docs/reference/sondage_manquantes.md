# Données de sondage avec valeurs manquantes

Base de données de service à la clientèle avec valeurs manquantes

## Utilisation

``` r
sondage_manquantes
```

## Format

Une base de données avec 1842 lignes et 10 variables:

- `wrkstat`:

  facteur, occupation

- `marital`:

  facteur, statut marital

- `childs`:

  nombre d'enfants

- `age`:

  âge (en années)

- `sex`:

  facteur, sexe de l'individu

- `rincome`:

  facteur, tranche de revenus

- `service`:

  variable binaire, réponse à la question "avez-vous utilisé nos
  services dans le dernier mois?", soit oui (`1`) ou non (`0`)

- `satisf`:

  Si vous avez utilisé nos services, indiquez votre niveau de
  satisfaction, sur une échelle de 1 à 5 où 1 est très insatisfait et 5
  très satisfait.
