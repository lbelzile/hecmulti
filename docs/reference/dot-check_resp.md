# Vérifications d'usage pour une variable binaire

Vérifications d'usage pour une variable binaire

## Utilisation

``` r
.check_resp(resp)
```

## Arguments

- resp:

  un vecteur numérique, binaire, logique ou un facteur

## Valeur de retour

un message d'erreur ou vecteur entier avec valeurs 0L ou 1L
