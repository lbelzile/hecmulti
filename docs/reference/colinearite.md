# Données colinéaires

Données simulées pour illustrer la colinéarité dans le cadre d'une
régression logistique

## Utilisation

``` r
colinearite
```

## Format

Une base de données avec 100 lignes et 6 variables:

- `y`:

  entier, variable réponse binaire

- `x1`:

  double, variable explicative

- `x2`:

  double, variable explicative

- `x3`:

  double, variable explicative

- `x4`:

  double, variable explicative

- `x5`:

  double, variable explicative
