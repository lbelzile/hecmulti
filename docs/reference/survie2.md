# Profils de clients

Quatre profils de clients pour le calcul de courbes de survie.

## Utilisation

``` r
survie2
```

## Format

Une base de données avec 4 lignes et 2 variables:

- `sexe`:

  variable binaire, soit femme (`1`) ou homme (`0`)

- `age`:

  âge du client au début de l’abonnement
