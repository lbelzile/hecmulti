# Correction de Bartlett pour analyse factorielle

Calcule une correction de Bartlett pour l'analyse factorielle

## Utilisation

``` r
bartlettcorr_factanal(object)
```

## Arguments

- object:

  objet de class `factanal`

## Valeur de retour

une liste avec les éléments suivants:

- `statistic`:

  statistique du rapport de vraisemblance fois correction de Bartlett

- `pvalue`:

  valeur-p pour la statistique modifiée
